# Sleep-health-lifestyle-analysis
Sleep health lifestyle data analysis using excel and Power BI

Project Overview
This project explores the relationship between sleep health and lifestyle factors using Microsoft Excel and Power BI.

The goal is to analyze how factors such as age, stress levels, physical activity, occupation, and BMI relate to sleep duration, sleep quality, and reported sleep disorders.

The project demonstrates the use of data cleaning, exploratory data analysis, data visualization, and interactive dashboard development.

Tools Used
Microsoft Excel – Data cleaning, formulas, PivotTables, and exploratory analysis.
Microsoft Power BI – Data transformation, DAX measures, and interactive dashboard development.
Dataset
Source: Sleep Health and Lifestyle Dataset – Kaggle

The dataset contains approximately 374 participant records and variables relating to sleep patterns, lifestyle habits, and health indicators.

Business Questions
1. What is the average sleep duration among participants?
2. How does stress level relate to reported sleep quality?
3. Is physical activity associated with sleep duration?
4. What is the distribution of reported sleep disorders?
5. How does sleep quality vary across age groups?
   
Project Workflow
1. Data Cleaning – Excel
   
Checked for duplicate participant IDs.
Reviewed missing values.
Checked data consistency.
Verified numerical data types.
Investigated unusual values.
3. Exploratory Data Analysis – Excel

Calculated descriptive statistics.
Analyzed sleep duration.
Compared stress levels and sleep quality.
Examined physical activity patterns.
Created PivotTables and charts.
4. Dashboard Development – Power BI

Imported the cleaned Excel dataset.
Prepared data using Power Query.
Created DAX measures.
Developed KPI cards and interactive visualizations.
Added slicers for gender, age group, and occupation.

Dashboard Features

Total participant count.
Average sleep duration.
Average sleep quality.
Average stress level.
Sleep disorder distribution.
Sleep quality by age group.
Sleep duration by physical activity level.
Interactive filters.

Limitations
The dataset is relatively small.
The data is synthetic and should not be interpreted as representative of the general population.
Observed relationships do not establish causation.
Findings should not be treated as clinical recommendations.
